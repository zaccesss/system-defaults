# Security Policy

## Scope

This repository is two shell scripts that change desktop preferences. It contains no service and
no library. In scope:

- A setting that weakens a security or privacy default without the reference saying so
- A script that runs something other than the preference commands documented in the reference
- Setup instructions that would leave insecure file permissions behind

## Out of scope

- A preference value being a matter of taste, such as Dock icon size
- Behaviour that changes between operating system versions

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
